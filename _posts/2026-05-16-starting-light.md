This is a sample post. To write a new one, add a Markdown file to `_posts` named like:

```text
2026-05-16-my-post-title.md
```

Use this front matter at the top:

```yaml
---
title: My Post Title
description: A one-line summary for the blog index.
---
```

Then write normally in Markdown.
